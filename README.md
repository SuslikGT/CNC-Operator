# ЧПУ Оператор

Мобильный справочник и набор калькуляторов для оператора токарно-фрезерного центра.
Работает офлайн, интернет нужен только для проверки обновлений.

**Автор: SuslikGT** · версия 1.2 · Android 7.0+

Станок: Headman T65M II/750 · Стойка: SINUMERIK 828D

## Что внутри

- **Режимы резания** — обороты по Vc, минутная подача, мощность и нагрузка шпинделя, момент.
- **Время и стоимость** — машинное и штучное время, цена операции и инструмента на деталь.
- **Геометрия и вес** — фаска, конус, галтель со схемами; масса и стоимость заготовки.
- **Резьба и отверстия** — метрическая, мелкая, UNC, UNF, трубная G, трапецеидальная; профиль и диаметры.
- **Шероховатость** — Ra/Rz от подачи и радиуса, допуски IT.
- **Перевод единиц** — мм/дюймы с дробями, SFM, подачи, HB/HRC.
- **Пластины ISO и державки** — разбор обозначений, формы, углы, крепления.
- **Свёрла, метчики, фрезы** — DIN, ISO-группы, покрытия, марки сплавов.
- **Марки сталей** — состав по ГОСТ, твёрдость, свариваемость, режимы.
- **Станок T65M II/750** — характеристики, узлы, приёмы оператора, частые ошибки.
- **Sinumerik 828D** — циклы, G/M-коды, программирование, шаблон программы.
- **Корректоры, стойкость, чек-лист** — рабочие мелочи наладки.
- **Источники** — ссылки и нормативы, откуда взяты данные.

## Установка

1. Скачайте `ЧПУ-Оператор.apk` из раздела **Releases**.
2. На телефоне разрешите установку из этого источника.
3. Откройте APK и установите. Данные (история, стойкость, чек-лист) сохраняются при обновлении.

## Обновления

- **Встроенная проверка**: раздел «Обновления» → источник `SuslikGT/CNC-Operator` → «Проверить».
  Приложение берёт последний релиз с GitHub и предлагает установку.
- **Obtainium**: добавьте `https://github.com/SuslikGT/CNC-Operator` — он будет следить за релизами.
- Новая версия: поднимите `versionCode`/`versionName` в `app/build.gradle`, соберите APK,
  создайте релиз с тегом `vX.Y` и прикрепите APK.

## Сборка

Требуется JDK 17, Android SDK 34, Gradle 8.9, AGP 8.5.2.

```bash
# 1. Ключ подписи (один раз)
keytool -genkeypair -v -keystore cnc-release.jks -alias cnc \
  -keyalg RSA -keysize 2048 -validity 10000

# 2. keystore.properties в корне проекта (в git не попадает)
cat > keystore.properties <<EOF
storeFile=../cnc-release.jks
storePassword=ваш_пароль
keyAlias=cnc
keyPassword=ваш_пароль
EOF

# 3. Сборка
gradle assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`
